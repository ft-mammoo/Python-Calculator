
# 🧮 Python Calculator

A simple command-line calculator built using Python, capable of performing basic arithmetic operations. This project is ideal for beginners looking to understand the structure of a Python script and command-line interaction.
## 📚 Project Module Description

- **Calculator.py**: The main script that runs the calculator. It contains the logic for user interaction and the implementation of arithmetic operations (addition, subtraction, multiplication, division).


## ✨ Features

- Perform basic arithmetic operations:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Handles invalid inputs and division by zero
- Simple and easy-to-use interface in the terminal


## 🛠️ Technologies Used

- **Python 3.x**

## ⚙️ Getting Started

### 🔄 Clone the Repository

```bash
git clone https://github.com/ft-mammoo/Python-Calculator.git
cd Python-Calculator
```

## 🐍 Set Up a Virtual Environment (Recommended)

### Create a virtual environment
```python -m venv venv```

### Activate it

#### On Windows:
```venv\Scripts\activate```

#### On macOS/Linux:
```source venv/bin/activate```


## ▶️ Run the Calculator

```python Calculator.py```
